feat(frontend): rediseño del dashboard de inferencia y validación de input en canvas

Se implementó una actualización mayor en la interfaz de usuario (UI/UX) para transformar la salida cruda de la API en un dashboard visual profesional, optimizando la interacción del usuario y protegiendo el backend.

CAMBIOS IMPLEMENTADOS:

* style: Migración a CSS Grid para renderizar las probabilidades (0-9) en dos columnas, optimizando el espacio vertical y garantizando un diseño responsivo en dispositivos móviles.
* ui: Incorporación de diseño neumórfico, bordes suaves y resaltado dinámico (verde esmeralda) exclusivo para el tensor ganador (Top-1).
* anim: Modificación de `frontend/static/js/app.js` para la inyección dinámica de HTML (barras de progreso) con un efecto de carga en cascada basado en delays secuenciales.
* perf(validation): Implementación de la bandera de estado `hasDrawn`. El frontend ahora intercepta y bloquea peticiones vacías hacia la API de Django, previniendo el consumo inútil de recursos de inferencia sobre "ruido blanco" e informando al usuario.

IMPACTO:

* La visualización de inferencia queda estandarizada en formato “dashboard” (probabilidades + Top-1).
* Se mejora la experiencia móvil y se reduce el riesgo de llamadas innecesarias al endpoint `/api/v1/predict/`.
* La capa de presentación queda finalizada y más alineada con estándares de producción.
